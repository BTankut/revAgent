# RevAgent Bridge

This is the provisional DP-1/M0 package boundary for the thin desktop bridge. It targets .NET 8, matching the recommended default and RES-2, but contains no service host, network transport, add-in client, journal, enrollment, or update behavior yet.

The operator must still confirm DP-1 before the M0 build-entry gate closes. If DP-1 changes, record the decision and consequences in `docs/decisions/DP-log.md` through the R-F amendment process before replacing this scaffold.
